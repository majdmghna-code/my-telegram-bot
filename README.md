# بوت تلغرام لحل الأسئلة والمسائل + اشتراكات + لوحة تحكم

## النشر المجاني (بدون أي دفع) — Render.com

### شو المطلوب منك بالضبط
1. سوي بوت جديد بـ `@BotFather` → `/newbot` → خد التوكن.
2. سوي حساب Anthropic (console.anthropic.com) وخد مفتاح API (رح تاخد رصيد تجريبي ~5$ تلقائيًا).
3. ارفع المشروع (نفس الملفات الحالية، بدون تعديل) على Render.

### خطوات الرفع على Render
1. روح على render.com وسجل حساب (ما بيطلب بطاقة بنكية للخطة المجانية).
2. ارفع مجلد المشروع على مستودع GitHub (لو رفعتو قبل لـ Railway، نفس المستودع منيح).
3. من لوحة Render: **New** → **Web Service** → اختار مستودع GitHub تبعك.
4. Environment: **Python 3**
5. Build Command: `pip install -r requirements.txt`
6. Start Command: `python bot.py`
7. اختار الخطة **Free**.
8. من قسم **Environment Variables** ضيف:
   - `TELEGRAM_BOT_TOKEN`
   - `ANTHROPIC_API_KEY`
9. دوس **Create Web Service**. بعد ما يخلص البناء، رح ياخدلك رابط عام (`xxx.onrender.com`) — هاد رابط لوحة التحكم.

### ملاحظات مهمة عن الخطة المجانية
- **ما فيها تخزين دائم:** لما تعيد نشر الكود أو يعيد Render تشغيل السيرفر، ملف `students.db`
  (بيانات الطلاب والاشتراكات) بينمسح ويبلش فاضي من جديد. هاد قيد بالخطة المجانية
  نفسها مش شي لازم تتصرف فيه هلق، بس خليه بالك.
- **بينام بعد 15 دقيقة بدون طلبات:** الخطة المجانية بتوقف السيرفر مؤقتًا لو ما حدا زار
  الرابط لفترة، وهاد ممكن يوقف رد البوت لحد ما يصحى. الحل: استخدم خدمة تنبيه مجانية
  زي **UptimeRobot** (uptimerobot.com) وضيفلها رابط لوحة التحكم تبعتك، وخلّيها تزوره كل
  5-10 دقايق — هيك السيرفر بيضل صاحي طول الوقت مجانًا.
- **ما في Webhook مطلوب:** البوت شغال بطريقة Polling متل ما هو بالكود، وهاي بتشتغل
  عادي بدون أي إعداد إضافي.
- **الذكاء الاصطناعي مش جزء من الاستضافة:** رصيد Anthropic API منفصل تمامًا عن
  الاستضافة، ولازم يضل فيه رصيد (تجريبي أو مدفوع) حتى يقدر البوت يحلل الأسئلة، بغض
  النظر وين استضفت المشروع.

## بديل: Railway (لو حبيت تجربه لاحقًا)
نفس فكرة Render تقريبًا، بس ممكن يطلب وسيلة دفع بعد فترة استخدام — إذا بدك تبقى
مجاني 100% بدون بطاقة، Render هو الخيار الأضمن حاليًا.

## كيف يشتغل نظام الاشتراك (للطالب)
- أول ما المستخدم يعمل `/start`، بيبلش معو أسبوع مجاني تلقائيًا.
- بعد ما تخلص الفترة المجانية أو الاشتراك، البوت بيوقف يرد على الأسئلة ويقلو يستخدم
  `/subscribe` لمعرفة الأسعار.
- `/subscribe` بيعرض الأسعار يلي حطيتها إنت من لوحة التحكم.
- الدفع نفسه مش مربوط بالبوت تلقائيًا — الطالب بيحولّك المبلغ بأي وسيلة عندك، وبعد
  ما تتأكد من الدفع، بتولدلو كود من لوحة التحكم (أو بتمدد اشتراكه مباشرة من اللوحة).
- الطالب بيفعّل الكود بكتابة: `/redeem الكود`
- `/status` بيوري الطالب صفو، مادته، وكم يوم متبقي.

## أوامر تلغرام

## لوحة التحكم (الويب)
بعد النشر، افتح رابط الموقع → سجل دخول بكلمة السر (افتراضيًا `SvoFrXYXkflQ`، **غيّرها**
بمتغير `ADMIN_PASSWORD`) → من فيها: تعديل الأسعار، توليد أكواد، تمديد/إيقاف اشتراك أي طالب.

## ملاحظات عامة
- بيانات الطلاب والأكواد والأسعار محفوظة بملف `students.db` (SQLite).
- الموديل المستخدم `claude-sonnet-5`، فيك تغيرو بمتغير `AI_MODEL` بأعلى `bot.py`.
- مدة التجربة المجانية `TRIAL_DAYS` بأعلى `bot.py` (افتراضيًا 7 أيام).
